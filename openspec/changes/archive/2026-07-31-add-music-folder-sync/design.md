## Context

Crate 目前把每次文件或文件夹导入视为独立任务：文件夹只枚举直接子项，`Song` 仅持久化绝对路径，后续磁盘变化由失效探测标记但不会主动更新曲库。新能力需要跨越文件枚举、元数据解析、曲库持久化、删除清理和资料库 UI，同时兼容既有 `library.json`。

## Goals / Non-Goals

**Goals:**

- 把用户选择的多个文件夹持久化为本地曲库来源，递归、异步并可取消地扫描。
- 用增量对账更新新增、同卷移动/重命名、修改和删除的文件，同时保留歌曲 id、分组引用和播放上下文。
- 来源不可访问或枚举失败时保留现有曲库记录，不把暂时离线的磁盘误判为删除。
- 不复制、不移动、不修改用户的音频、封面或歌词文件。

**Non-Goals:**

- 本次不接入 FSEvents 实时监听；启动后台扫描和用户主动重新扫描是首版刷新入口。
- 不实现跨卷移动的确定性身份保持；跨卷复制会按旧文件删除、新文件新增处理。
- 不新增标签编辑、音乐文件整理、云同步或联网元数据能力。

## Decisions

### D1：来源与曲库一起原子持久化

新增 `MusicFolderSource`，保存稳定 id、显示名称、最后解析路径和可选 bookmark data；`PersistedLibrary` 增加带默认值的 `musicFolders`。`Song` 增加可选的 `sourceFolderId`、`fileIdentity`、`fileModificationDate` 和 `fileSize`。所有新增字段保持可选或提供自定义解码默认值，使旧版 JSON 可直接迁移。

相比单独维护第二个来源文件，把来源放进同一曲库快照可以保证来源增删与歌曲归属一致地原子写入。bookmark 优先恢复用户选择目录，路径作为非沙盒构建和 bookmark 失效时的回退。

### D2：扫描按来源独立枚举并只提交成功来源

每个来源使用 `FileManager` 目录枚举器递归遍历、跳过隐藏项和包内容，只收集支持格式的常规文件。某个来源无法解析或枚举时将其记为失败，不参与删除对账；其他成功来源仍可提交结果。

扫描沿用单一后台任务与现有进度 UI。启动扫描仅在应用加载和播放记忆恢复后异步触发；截图模式不读取来源也不扫描。

### D3：路径、文件身份与签名分层匹配

扫描先用标准化路径匹配已有歌曲，再用 `volume system number + file system number` 组成的文件身份匹配同卷移动或重命名。匹配后保留歌曲 id，仅更新 URL 和来源归属。文件的修改时间或大小发生变化时重新解析元数据；未变化时跳过 AVFoundation 读取。

仅属于已成功扫描来源、且本轮既未按路径也未按身份发现的歌曲会被移除。手工导入歌曲没有来源 id，不受扫描删除影响。移除来源时清除相关歌曲的来源 id，但保留歌曲记录。

### D4：复用元数据与专辑归并，提交后清理孤儿

扫描新增和修改文件复用现有解码探测、元数据读取、封面准备和专辑归并规则。修改歌曲时允许重新关联专辑；全部歌曲更新完成后统一删除没有歌曲引用的专辑，避免旧专辑残留。

扫描删除歌曲复用统一的批量移除路径，同步清理分组、播放器上下文、选择态、歌词页与失效集合。当前歌曲被删除时按现有删除语义停止播放。

### D5：来源管理集中在资料库头部

导入菜单把“导入文件夹”改为“添加音乐文件夹…”，选择一个或多个目录后立即登记并扫描。更多菜单新增“音乐文件夹…”和“重新扫描音乐文件夹”；管理页展示路径，支持添加、移除和扫描。重复选择相同或相互嵌套的来源会被拒绝，防止重复遍历和归属不确定。

## Risks / Trade-offs

- [超大曲库首次递归扫描耗时] → 全程后台运行、显示文件级进度、支持取消，并在后续扫描按文件签名跳过未变化元数据。
- [外接盘临时离线导致误删] → 只有成功解析且完成枚举的来源才执行删除对账；失败来源保留歌曲并提示。
- [文件身份在跨卷复制后改变] → 明确按删除加新增处理；同卷重命名和移动保留 id。
- [扫描与用户同时修改曲库发生竞争] → 后台仅生成不可变结果，主线程提交前按歌曲 id/path 再匹配；应用继续限制同一时间只有一个导入或扫描任务。

## Migration Plan

旧曲库解码时将来源列表默认为空，新 `Song` 字段为 `nil`；现有手工导入记录完全保留。用户首次添加来源时，路径相同的已有歌曲会被认领到该来源而不重复创建。回滚旧版本时新增 JSON 字段会被 Swift `Codable` 忽略，但旧版本不会继续维护来源同步。

## Open Questions

无。实时文件监听、跨卷身份迁移和标签编辑留给后续独立变更。
