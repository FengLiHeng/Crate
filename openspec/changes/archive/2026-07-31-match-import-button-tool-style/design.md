## Context

导入按钮使用 `ToolButtonChrome`，但传入 `emphasized: true` 后会采用强调色图标和强调色悬停背景。相邻工具按钮均使用该组件的默认中性色，因此不需要新增或修改共用样式。

## Goals / Non-Goals

**Goals:**

- 导入按钮的常态图标色和悬停背景与同组工具按钮一致。
- 保持导入功能和既有反馈不变。

**Non-Goals:**

- 不修改 `ToolButtonChrome` 的默认样式。
- 不调整工具栏布局、图标、尺寸或动画。

## Decisions

1. 移除导入按钮调用中的 `emphasized: true`，直接使用组件默认样式。相比修改颜色表达式或增加专用样式，这能确保导入按钮持续继承同组按钮的视觉规则。
2. `emphasized` 在仓库中没有其他调用者，因此同时删除该参数及其条件分支，避免保留无效的红色特殊路径。

## Risks / Trade-offs

- [导入入口不再使用红色强调] → 通过固定位置、`+` 图标和“导入音乐文件”提示保持可发现性。
