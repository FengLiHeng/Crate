## Context

头部 `+` 当前通过自建 `NSMenu` 同时提供文件导入和音乐文件夹添加；“更多操作”又提供音乐文件夹管理页，而管理页内部已经具备添加、移除和重新扫描功能。重复入口增加理解成本，也引入了一套只服务于该菜单的 AppKit 目标保活代码。

## Goals / Non-Goals

**Goals:**

- `+` 成为单一、可预期的音乐文件导入按钮。
- 音乐文件夹来源只通过管理界面添加和维护。
- 删除不再需要的 AppKit 菜单桥接，不改变视觉尺寸和主题样式。

**Non-Goals:**

- 不改变文件选择面板、文件夹管理页或后台导入扫描逻辑。
- 不调整工具栏其他按钮的顺序与造型。

## Decisions

1. 保留现有强调样式的 `+`，点击时直接调用 `AppState.importViaPanel()`；相比更换图标或增加新文案，现有位置和视觉记忆无需重新学习。
2. 删除 `ImportMenuActionTarget` 及仅供旧菜单调用的 `importFolderViaPanel()` 转发方法，不保留只有一个动作的菜单；标准 SwiftUI `Button` 已足够。
3. 保留“更多操作 → 音乐文件夹…”以及管理页底部“添加文件夹”，它是来源生命周期操作的唯一入口。

## Risks / Trade-offs

- [用户可能仍把 `+` 理解为通用添加] → tooltip 和辅助功能标签明确使用“导入音乐文件”。
- [原来从 `+` 添加文件夹的路径消失] → 文件夹管理入口保持在相邻的“更多操作”菜单中，并在管理页内直接提供添加按钮。
