## 1. 播放记忆持久化

- [x] 1.1 在 `PlayerStore` 中定义可编码的播放记忆快照，包含当前歌曲、进度、播放上下文、插播队列、随机和循环状态。
- [x] 1.2 为播放记忆配置 Application Support 下的独立存储文件，并实现读取、节流保存、同步 flush 和无效记忆清理。
- [x] 1.3 在播放状态变化、拖动进度、定时进度推进、暂停/停止/切歌/清空播放会话时触发播放记忆保存。

## 2. 启动恢复

- [x] 2.1 在曲库加载、索引重建和 `songProvider` 注入完成后恢复播放记忆。
- [x] 2.2 恢复时校验当前歌曲仍存在，并将进度限制到歌曲时长范围内。
- [x] 2.3 恢复时过滤上下文和插播队列中已不存在的歌曲，并重新对齐当前上下文位置。
- [x] 2.4 对真实文件执行存在性检查；文件不可用时静默清理播放记忆并回退到未播放状态。
- [x] 2.5 确保恢复后 `isPlaying` 为 `false`，不创建播放引擎、不启动进度计时器、不自动输出音频。

## 3. 手动播放续播

- [x] 3.1 调整播放/暂停切换逻辑，使恢复态下 `currentId` 存在但播放引擎为空时，可以从恢复进度构造引擎并开始播放。
- [x] 3.2 复用真实文件和示例曲目的现有播放路径，确保手动播放后从恢复进度继续。
- [x] 3.3 保持现有上一首/下一首、随机、循环、插播队列和歌词入口行为不变。

## 4. 退出与删除同步
